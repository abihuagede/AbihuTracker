# AbihuTracker

**AbihuTracker** is a simple and lightweight IP geolocation tracker built using HTML, CSS, JavaScript, and the [ipstack API](https://ipstack.com/). It allows users to input an IP address and receive detailed location information including city, region, country, and more.

🔗 **Live Website:** [https://abihuagede.github.io/AbihuTracker/tracker.html](https://abihuagede.github.io/AbihuTracker/tracker.html)

![Screenshot 2025-05-02 215755](https://github.com/user-attachments/assets/71fd0b2b-2ad5-46b9-a121-40b6ef21d348)

## 📌 Features

- Search for location details of any IP address
- Displays:
  - IP Address
  - City, Region, and Country
  - Latitude and Longitude
  - Timezone
  - ISP
- Responsive design for mobile and desktop

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [ipstack API](https://ipstack.com/)
